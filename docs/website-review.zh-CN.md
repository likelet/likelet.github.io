# 网站分析与本轮优化

检查日期：2026-11-19。定位：兼顾赵琦个人介绍与课题组展示。

## 主要发现与处理

| 问题 | 影响 | 本轮处理 |
| --- | --- | --- |
| 首页主要介绍团队，个人资料入口位于成员页深处 | 访客难以快速了解负责人 | 首屏加入已有个人照片、简短介绍、个人资料及论文入口，导航增加 About Qi Zhao |
| 首页 Latest Preprints 没有数据 | 页面显得未完成 | 用真实论文数据中的三篇精选成果替代，按编号倒序展示 |
| 首页新闻较长、装饰背景源图约 12.9 MB | 主线不清晰，增加不必要的媒体依赖 | 新闻缩减到三条；移除首页对装饰背景和自动播放视频的引用，原始素材保留 |
| 十位成员包含示例邮箱、模板作者 GitHub 和无关人物简介 | 降低可信度，可能误导联系 | 删除明确的示例链接和重复模板正文，保留成员姓名、身份及教育字段 |
| 个人邮箱未使用 mailto | 可能被当成站内路径 | 修复邮箱链接 |
| 联系表单配置为 Netlify，发布流程为 GitHub Pages | 未见可用的表单处理服务 | 停用表单，显示公开邮箱及联系说明 |
| 页脚署名为 Me | 明显模板残留 | 改为 Qi Zhao Research Group，保留原许可证 |
| 部分新闻使用 linc/link 作为链接文字 | 读者不知道链接用途 | 改为 Read the publication |
| 论文摘要模板直接输出 Markdown | 加粗标记可能直接显示 | 使用 Markdown 渲染；论文图片增加延迟加载 |

## 验证记录

- 原版与修改版均通过本机 Hugo Extended 0.160.1 构建，输出 75 页。
- 对比八项生成页面检查：个人链接、精选成果、肖像尺寸、空栏目清理、示例邮箱清理、邮箱链接、联系表单、页脚署名；原版八项不符合目标，修改版八项全部通过。
- 首页所有站内链接和图片路径均对应实际生成文件。
- 构建存在原主题的弃用提示和 sitemap 渲染钩子提示，原版也有这些提示。
- 浏览器无法连接本地预览服务，尚未完成桌面、移动端及暗色主题的视觉验收。
- 尚未运行 Lighthouse，也未以线上 GitHub Actions 所用的 Hugo 0.128.0 重建；不作性能分数或上线验证承诺。
- 修改仅保留在本地 optimize/personal-and-group 分支工作区，未提交或推送到 GitHub。

## 仍需本人核实

1. 个人及成员的 Interests 多处写着 Computational Linguistics / Information Retrieval，可能是模板遗留，但无法据此判断真实研究兴趣，暂保留。
2. 个人教育经历的年份与正文对应入学或入职年份，模板并未注明；建议确认后统一为起止年月。
3. 成员的教育经历、职称及真实联系方式需分别核实，不能以模板资料替代。
4. 论文数量、获奖、专利与职称等原始陈述未进行独立事实核查，本轮未新增此类声称。
